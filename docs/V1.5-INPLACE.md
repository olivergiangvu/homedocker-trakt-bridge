# HomeDocker v1.5 beta — direct in-place update (NO parallel Bridge)

This beta fixes the **UI-refresh hint only after an AIO import**. AIOStreams remains upstream `latest`, configuration-only. Production v1.4.0 remains the rollback image. The GitHub connector cannot SSH into HomeDocker; branch changes do not imply host deployment.

## 1. Read-only operator preflight

Verify the **one** running `trakt-bridge`, its Compose project, the actual Compose file(s) and the read-only AIO mount:

```bash
sudo docker inspect trakt-bridge --format '{{.Config.Image}} {{index .Config.Labels "com.docker.compose.project.working_dir"}} {{index .Config.Labels "com.docker.compose.project.config_files"}} {{index .Config.Labels "com.docker.compose.project"}}'
sudo docker inspect trakt-bridge --format '{{range .Mounts}}{{.Destination}}:ro={{not .RW}} {{end}}'
sudo docker ps --format 'table {{.Names}}\t{{.Image}}' | grep -E 'trakt-bridge|NAME'
```

STOP when owner/path is missing, Portainer-managed files are inaccessible, or Compose does not select the Bridge image with `TRAKT_BRIDGE_IMAGE`. Do not invent a separate compose stack or duplicate writer.

## 2. Existing Bridge service only

From the *actual* Compose directory, make protected copies of `.env`, Compose files and an online SQLite backup of existing `/app/data/bridge.db`. Do not `docker compose down`, run a second Bridge, delete volumes or restore DB as part of a normal upgrade.

Build the reviewed beta branch once:

```bash
git clone --depth 1 --branch beta/watch-state-freshness-v1.5 \
  https://github.com/olivergiangvu/homedocker-trakt-bridge.git /tmp/homedocker-trakt-bridge-v15
sudo docker build -t homedocker-trakt-bridge:1.5.0-beta.1 /tmp/homedocker-trakt-bridge-v15
```

Use the existing Compose `.env` selector:

```dotenv
TRAKT_BRIDGE_IMAGE=homedocker-trakt-bridge:1.5.0-beta.1
JELLYFIN_GATEWAY_WS_NOTIFY_ENABLED=true
```

The existing `JELLYFIN_GATEWAY_ENABLED=true`, exact `JELLYFIN_GATEWAY_SOURCE_KIND=aiostreams`, `JELLYFIN_GATEWAY_USER_ID`, `JELLYFIN_GATEWAY_PROFILE_ID`, `JELLYFIN_GATEWAY_UPSTREAM_URL` and **read-only** AIO mount must remain as-is. Use precisely the original Compose project and all its original `-f` files to run `docker compose config --quiet` followed by `docker compose up -d --no-deps --force-recreate trakt-bridge`. Verify its health and version.

## 3. One exact WebSocket location, NOT whole Jellyfin API

Only in the host nginx `server {}` block serving the user's **AIOStreams Web/Desktop Jellyfin host**, proxy its exact WebSocket route to the existing mapped Gateway listener (usually `127.0.0.1:7101`). First verify `curl -fsS http://127.0.0.1:7101/health` succeeds, and that the active location ordering does not skip regex blocks.

```nginx
location ~* ^/jellyfin(?:/[^/]+/[^/]+)?(?:/(?:emby|mediabrowser))?/(?:socket|websocket)$ {
    proxy_pass http://127.0.0.1:7101;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
}
```

Do not proxy `/jellyfin/` wholesale or remap streaming, NextUp, Resume, metadata or static Web. Apply only after `nginx -t` and via `systemctl reload nginx`. Clients may need one reconnect to establish their WebSocket on the new route.

## 4. AIO freshness setting (independent, supported config only)

The AIO runtime currently has no overrides and schedules a Bridge background read every ~1800 seconds. If and only if editing the existing AIO Compose config, set `WATCH_STATE_PULL_INTERVAL=300` seconds in AIO's environment and recreate **only** `aiostreams`. Leave `WATCH_STATE_PULL_TTL=300`, default sweep and Bridge cache 60 seconds unchanged. Avoid blanket 15-second polling. Note the 5-min end-to-end detection bound is still incompatible with a guaranteed 15-second UI freshness SLA.

## 5. Minimal acceptance, then stable

- One newly completed episode on Trakt appears as `origin=import` from the Bridge sink; Web and Desktop with their sockets open update **without page reload** after that import.
- One skipped/unwatched episode should disappear when imported removal is detected.
- No synthetic played/unplayed, duplicate Trakt POST, 429 spike, broken native WS commands or broken NextUp.

On failure: remove the exact nginx WebSocket location and reload nginx, disable `JELLYFIN_GATEWAY_WS_NOTIFY_ENABLED`, or restore the protected `.env` image selector and recreate only the Bridge service with the retained immutable v1.4 image. No AIO DB rewrite and no parallel deployment. Promote v1.5 stable only after one actual Web/Desktop client check.
