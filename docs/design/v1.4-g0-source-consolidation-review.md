## Deliberately excluded from shipping source

- `src/gateway-standalone.mjs`, `src/gateway-canary-entry.mjs`, `Dockerfile.gateway-canary*`: separate canary executables are not the Unified Bridge.
- R23B2 host trial launcher, Unix socket/netns transport, Python sample sidecar and SIGKILL recovery wrappers: **already-proved experimental transport**, not an app dependency or a mandatory production subsystem.
- Entire R23D nftables/tc/systemd/guardian/boot-fence/QEMU/fault injection program and CI jobs.
- Retired R23A canary restore or a copy of stale `scripts/audit-v140-r23d-host-preflight.py`. R23A exact container was deliberately retired in PR #103. A *new* G3 production baseline/backup verifier will check RC6/R22/digest and active network assumptions against **current** host facts instead.
- Real credentials, AIO SQLite/mounts, Trakt OAuth material, third-party client modifications, nginx route changes, and any production migration tool.
- Version changes (`package.json` and `APP_VERSION` remain `1.3.0` until feature is qualified) and release workflow edit/tag publishing. The existing v1.4 release workflow HOLD is preserved.

## Current integrity constraints

- Gateway enabled only by explicit configuration. Default `JELLYFIN_GATEWAY_ENABLED=false`, `JELLYFIN_GATEWAY_LEGACY_IMPORT=off`, `JELLYFIN_GATEWAY_RESUME_PASSTHROUGH=false`.
- One Bridge database, one Trakt writer and one dashboard; Gateway only augments read-only response rendering. No extra permanent profile store/dashboard.
- Same-user `/Users/Me` check required before any NextUp identity projection, and only verified exact aliases can be normalized.
- Unverified/mismatched user, stale graph, competing resumptions and ambiguous metadata fail open to original upstream AIO response.
- The script/test imports must not modify AIO source/image/database or restart HomeDocker services.
