**Established on HomeDocker (2026-10-17):** One *real* Odin pilot session using a separate native macOS Jellyfin server entry through the temporary SSH tunnel and loopback-only observer returned 34 requests. `GET /jellyfin/Shows/NextUp`: 1, **HTTP 200**; Resume: 1, **2xx**; Other: 32, with **7×2xx, 21×3xx, 1×4xx, 3×5xx**. No playback/watch-state write requests were forwarded, no production SQLite writes, no existing nginx reload, and the observer was removed. There was **zero actual Gateway interception**.

**Decision:** successful NextUp GET qualifies the Odin endpoint as technically relevant to Gateway filtering. However, three unclassified Other-route 5xx require investigation before authorizing G2-1B. Do **not** infer these are fatal AIO errors, or dismiss them as artwork errors: neither source nor request family has yet been observed. Overall 3xx could be 304 caching, not necessarily redirects.

## This change: error-family diagnostics, not client routing

An opt-in repeat of the **same** temporary, non-root nginx observer now logs a third **static constant** alongside category and status:
`<nextup|resume|userdata|auth|other> <three-digit HTTP code> <static endpoint family>`.

The final report adds `other_errors_by_endpoint_family`, a fixed-size aggregate 4xx/5xx summary across **items, shows, users, images, media, system, jellyfin_other, aio_other**, for all OTHER requests. The family is classified transiently by an nginx `map $uri` with constant outputs. Even if `$uri` includes identifying path segments, nginx logs ONLY the static family name, not the path, user ID, config alias, IMDb ID, title, cookie, headers, token, query, request body, IP address or User-Agent. The restricted temporary log is deleted on Ctrl+C with the original observer and never uploaded. Group names are coarse; a family alone **does not prove** whether the 5xx originated in the observer or the upstream AIO/metadata subsystem.

Existing counts remain, including `nextup_http_200_observed`, route-level 2xx/3xx/4xx/5xx, `gateway_forwarded_requests=0`, and `real_gateway_client_qualified=false`. There is **no new nginx location, proxy destination, HTTP method permission, Docker/Gateway service, production file or public listener**. AIO remains on localhost 3240, observer on localhost 17431, and Odin on Mac through a separate SSH tunnel. RC6 stable release HOLD remains.

### Interpretation of the next sanitized result

- **Other 5xx only in media/images** with NextUp/Resume 2xx, Odin browsing functioning: inspect cache/content origin; this might be nonblocking for NextUp-only pilot, but requires explicit review. Do not automatically PASS G2-1B.
- **Other 5xx in users/system/items/shows**: treat as potentially critical library/auth/metadata failure. Stop selective interception until explained.
- **No Other 5xx on repeat**: intermittent earlier errors still documented, not erased. Compare samples; avoid premature release signoff.
- **Any NextUp/Resume 4xx/5xx**, 5xx surge, repeated failed auth or bad UI navigation: stop and fix upstream/preview, no Gateway route.
