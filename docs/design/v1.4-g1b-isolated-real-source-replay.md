# G1B — Real-AIO-source isolated Gateway replay (memory only)

**Status:** G1B implementation under Draft review; `V140_STABLE_RELEASE_HOLD` is unchanged. This is **not** a real client's HTTP route, an authenticated end-to-end AIO↔Gateway connection, or a production Identity Graph migration.

## Motivation

HomeDocker G1A operator evidence from 2026-10-17: one AIO login POST succeeded; authenticated `/Users/Me` and `/Shows/NextUp?Limit=20` returned 20 stable real items and **zero alias pairs**. Bridge RC6 retains 1 connected profile, 17 verified legacy show mappings, 1 alias group, zero persisted new graphs. An unaffected live response alone cannot prove normalization. Do not modify AIO watch state to manufacture a duplicate.

## What this adds

- `scripts/audit-v140-g1b-isolated-replay.py`: fixed-host, read-only snapshot collector that prompts privately for **one existing AIO token (GET only)** or **one new AIO username/password login POST** followed by GETs. Reads exact production Bridge `bridge.db` only in SQLite `mode=ro`, `PRAGMA query_only=ON`, consistent transaction, and tests the RC6 pinned image reference. Captures only 20 AIO NextUp items and same-session series `ProviderIds.Imdb`, ensuring source stability.
- `scripts/replay-v140-g1b-candidate.mjs`: actual v1.4 `importLegacyIdentityAliases()` and `createJellyfinGateway()` execute in memory; one detached **real AIO source snapshot is replayed**, confirming **unchanged** response in the absence of a verified pair; then the actual JS filter receives two **new synthetic episode records that live ONLY inside the isolated process**, verifying `2→1` (active canonical wins), two active resumes preserved and mismatched user preserved. No writes to source, AIO, Trakt or history.
- Node and Python tests exercise actual Gateway listener, no-secret output and stop-the-line guards, wired through the existing CI. No persistent Gateway, separate dashboard, Docker socket, source patching to AIO, new release workflow or nginx route.

The host Python transfers `Bridge profile ID, raw legacy cache, AIO User ID, real captured NextUp rows and limited Series IMDb details` **through a bounded RAM-only stdin pipe** to the disposable container. These are sensitive *media/account metadata* (not login credentials), are not saved to disk, not printed and remain ephemeral. The actual AIO username/password, token, RC6 encrypted Trakt OAuth credentials, `compose.env`, or any SQLite DB **never enter the container**.

Docker runtime: **already running RC6 local image ID**, exact image pin verified; `--rm -i --network none --read-only --cap-drop ALL --security-opt no-new-privileges --user 1000:1000 --pids-limit 32 --memory 128m --cpus 1`; read-only temporary Git checkout mount, no AIO/Bridge data mounts, no Docker socket, no published port, Node only listens on 127.0.0.1 inside isolated netns. The only writes are one importer insertion in an ephemeral JavaScript Map. The container removes itself; if STOP on cleanup, do not broadly prune.

## Operator-controlled replay (separate opt-in)

After preflight, choose **one**:

```bash

sudo python3 -B scripts/audit-v140-g1b-isolated-replay.py \
  --mode existing-token --confirm V140_G1B_SNAPSHOT_EXISTING_TOKEN_MEMORY_ONLY

# No token: hidden AIO username/password, exactly one AIO session-creating login POST:
sudo python3 -B scripts/audit-v140-g1b-isolated-replay.py \
  --mode login --confirm V140_G1B_ONE_AIO_LOGIN_MEMORY_ONLY
```

The operator must run under an interactive SSH TTY, type the secret in the *hidden prompt*, never pass it in argv, GitHub, logs or chat. The script may fail closed if the RC6 image pin, existing graph records, alias provenance or AIO user/media state differs from the previous observed baseline.
