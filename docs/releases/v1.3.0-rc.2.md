# v1.3.0-rc.2

This canary hardens HomeDocker against a reproduced AIOStreams/Jellyfin false-`unplayed` echo without changing the v1.3 compare-only recovery model.

## What changed

- Adds opt-in `AIO_UNPLAYED_ECHO_GUARD=true`.
- Suppresses a single-item AIO `unplayed` only when the exact delivery is proven to contradict AIO's own final local resume state.
- Requires an equivalent **delivered** HomeDocker playback event at the same positive position before suppression.
- Fails open to the existing Trakt `/sync/history/remove` path whenever evidence is missing, ambiguous, stale, or unavailable.
- Keeps bulk watched/unwatched marks unchanged.
- Keeps explicit Mark Unwatched unchanged.
- Keeps AIO SQLite read-only.
- Adds no DB migration and no Phase B recovery writeback.

## HomeDocker evidence

The issue reproduced on both AIOStreams stable 2.35.9 and exact nightly `2026.10.04.1829-nightly`.

Fresh nightly canary case:

- item: `e|tt14261112:2:6`
- final AIO local state: `played=0`, `position=398930/1740000`
- delivered HomeDocker stop: `398928ms`
- later AIO push: `unplayed`, `positionMs=0`, `played=false`

AIO's Jellyfin UserData route currently handles `Played=false` before a positive `PlaybackPositionTicks` in the same request, allowing the outbound queue to contain `unplayed` even though the final local row remains resumable.

## Guard acceptance

The RC2 guard requires all of these before it ignores an `unplayed`:

1. single movie/episode event;
2. exact AIO delivery event ID on the configured HomeDocker sink;
3. `played=false`, `positionMs=0`, valid duration;
4. current AIO row is `origin=local`, `played=0`, `position_ms>0`;
5. current row is contemporaneous with the contradictory unplayed delivery;
6. a delivered HomeDocker start/pause/stop carries the same positive resume position within the configured lookback/tolerance.

Any failed condition preserves the existing history-remove behavior.

## Canary configuration

```env
AIO_RECONCILER_MODE=compare
AIO_UNPLAYED_ECHO_GUARD=true
```

The public default remains `AIO_UNPLAYED_ECHO_GUARD=false`.
