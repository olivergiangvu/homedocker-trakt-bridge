# v1.2.0-rc.6 — settled AIO local-state detector

Status: **release candidate / HomeDocker detect-only canary**.

Stable remains `v1.1.0`. rc.5 remains the current HomeDocker runtime canary until rc.6 is published and explicitly enabled.

## Why rc.6 exists

The first rc.5-A Strand canary proved that a simple 30-second age gate is too eager to treat a local AIO resume row as final.

Observed for `tt10009170:2:7`:

```text
previous canonical     07:23 / 443904 ms
intermediate AIO row   06:02 / 362934 ms
final AIO row          08:56 / 536771 ms
final Trakt state      08:56 / 536771 ms
watch_sessions         0
Bridge playback events none (unplayed only)
```

The two AIO position writes were about 180.4 seconds apart. A 180-second quiet window would therefore also be unsafe.

## What changes

rc.6 remains detect-only but changes candidate semantics:

- one persistent pending candidate per AIO user/persona/item;
- a newer local row replaces the pending row and restarts its quiet timer;
- default settlement requires **300 seconds unchanged**;
- the first rc.6 run creates a fresh v2 baseline and does not replay rc.5 history;
- playback-delivery coverage is evaluated only against the configured HomeDocker sink;
- the sink can be pinned by AIO addon instance ID;
- only settled classifications are written to the Bridge event log;
- pending state survives Bridge restarts.

## Exact sink matching

Recommended HomeDocker settings:

```env
AIO_RECONCILE_SINK_NAME=homedocker-trakt-bridge
AIO_RECONCILE_SINK_INSTANCE_ID=e3fe3b0
```

If the sink cannot be resolved uniquely, rc.6 blocks settlement rather than accepting a delivery from another sink such as AIOMetadata.

## Safety

rc.6 does **not**:

- modify AIOStreams code or configuration;
- write the AIOStreams SQLite database;
- call Trakt from the reconciler;
- synthesize playback events;
- write or rewind Trakt.

The 300-second quiet window reduces false finalization but is not proof that playback ended. Any future write-capable recovery phase must still compare the settled AIO state with current Trakt playback and fail safe on ambiguous or backward recovery.
